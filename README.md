# SPACE RELICS — NASA Space Archive

A small interactive storytelling website about historic space exploration machines.

## Files
- `index.html` — website structure
- `style.css` — visual design and responsive layout
- `script.js` — mission filters and story interactions

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all three files (`index.html`, `style.css`, and `script.js`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section.
